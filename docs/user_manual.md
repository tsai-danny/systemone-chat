# SystemOne 測試台 使用手冊

給第一次接觸的人。**邊讀邊做**，每節都有可以立刻動手的事。

## 這系統是什麼？

一個讓 AI 模型**做選擇題**的測試台。

- 你給它一段文字（例如客戶抱怨）＋ 幾個問題
- 它回你「答案＋信心程度」
- 它**不會生成文字**，只做一次判斷，所以超快（幾十毫秒）

三個工具：

| 檔案 | 用途 |
|---|---|
| `index.html`（根目錄） | 單一進入點，自動進入測試台 |
| `spa/index.html` 測試台 | 自己組問題、送出、看結果 |
| `spa/compare.html` 檢測台 | 同一情境用英文/中文/混雜各測一次，比一致性 |
| `docs/systemone_api.md` | 規格書（想深入時再看） |

---

## 第 0 步：確認服務在線

打開根目錄的 `index.html`（啟動頁，會自動進入測試台），右上角有狀態燈：

- **上線 · 模型：xxx** → 可以開始玩
- **離線** → 需要有人先啟動 llama-server（問同事，見附錄）

網址列預設 `http://localhost:8080/v1/systemone`，本機測試不用改。

---

## 30 秒完成第一次測試

1. 「載入預設範例」選 **入門：choice 基本型**
2. 按 **送出請求**
3. 右側出現結果：選了哪個選項、信心多少

就這麼簡單。現在就試。

---

## 認識編輯區（左側）

| 區塊 | 白話說明 |
|---|---|
| **state** | 要評估的內容（一段文字／JSON／對話） |
| **images** | 選填，放圖片（需模型支援 vision，一般不用） |
| **questions** | 你要問的問題，至少一個 |

問題有三種題型：

- **choice** 選擇題 → 回選項＋機率（總和=1）
- **score** 評分題 → 回加權分數（等級由低到高排）
- **noul** 是非題 → 回「是」的機率

---

## 預設範例怎麼用

下拉選單分三組：

- **入門範例**：單一題型，先從這玩
- **內建範例（三語）**：客服工單／內容審核／Agent 自評，各有純英、純中、混雜版
- **我的預設**：你存的問題

選一個 → 自動填進編輯區 → 送出。

> 💡 選完後選單會清空，這是刻意的：載入後你可以**隨意修改**，
> 再選一次同一範例＝還原。表單內容才是送出的依據。

---

## 修改與自存預設

1. 載入任一範例
2. 改 state 文字、改問題、加減選項
3. 按 **儲存預設** → 取名 → 之後從「我的預設」取回

想確認送出的內容：勾 **預覽請求 JSON**。

---

## 看懂結果

- **choice**：`route → billing (0.92)` ＝ 選 billing，信心 92%
- **score**：`urgency → 2.31` ＝ 落在第 2~3 級之間（加權期望）
- **noul**：`angry → 0.89` ＝ 89% 機率是 true
- **confidence**：答案有多確定（0~1）。答案對但信心低＝模型在猜

下方 **歷史紀錄**：點任何一筆可把該請求載回編輯區，方便重測。

## 三語檢測台（spa/compare.html）

想知道「模型懂不懂中文」？

1. 右上角按 **語言能力檢測**
2. 選情境 → **執行比對**
3. 看表格：en／zh／mix 三欄答案是否一致

判讀：

- choice 三欄全同 ＝ 語義穩定
- 分數差 ≤0.15 相近 ／ ≤0.35 輕微偏移 ／ >0.35 分歧
- 右側 **模型語言矩陣** 告訴你哪些模型支援中文
  （Julia-1、OpenJev 支援；Laya、Kev-4B、lev 僅英文⚠）

## 常見問題

**送出後顯示離線／連線失敗？**
服務沒啟動。先確認狀態燈是「上線」。

**出現 501 錯誤？**
通常是送了圖片但模型不支援 vision，把 images 清空。

**中文結果怪怪的？**
先看語言矩陣：僅英文模型測中文本來就會偏移——這正是檢測台要抓的現象。

**結果每次一樣嗎？**
一樣。這是單次判斷，不生成文字，輸入相同輸出就相同。

## 附錄：啟動 server（需要的人看）

```shell
llama serve -hf ggml-org/Julia-1-GGUF
```

- 模型需為 llama.cpp 的決策模型：Julia-1（144M，支援中文）、Laya（421M，僅英文）、
  Kev-4B、lev（4B，僅英文）、OpenJev（27B，支援中文＋圖片）
- quant 預設 Q4_K_M，可加 `:Q8_0` 等
- 啟動後瀏覽器重新整理，狀態燈變「上線」即成功
- 換模型＝換 `-hf` 的名稱重啟；**測中文請用 Julia-1 或 OpenJev**
- 詳細規格與啟動選項見 `systemone_api.md`
